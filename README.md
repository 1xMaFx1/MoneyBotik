# MoneyBotik для iPhone · 2.0

Автономный личный бюджет: нативное приложение SwiftUI, локальный голос, доходы, расходы, счета, накопления и отчёты. Учебный проект на SwiftUI для изучения локального хранения, разбора текста, финансовых расчётов и интерактивных диаграмм.

## Что можно делать

- Вводить несколько доходов и расходов текстом или голосом в одном сообщении.
- Проверять и исправлять распознанные операции перед общим сохранением.
- Вести доходы по видам: зарплата, подработка, бизнес, инвестиционный доход, подарки, аренда, кешбэк, другой доход.
- Вести расходы по категориям, отдельно отражать возвраты.
- Создавать счета, задавать начальные остатки, переводить деньги между счетами.
- Помечать счета как накопления и задавать денежные цели.
- Смотреть личный P&L: доходы, расходы за вычетом возвратов и результат. Это учёт по фактическим платежам, а не бухгалтерский отчёт по методу начисления.
- Фильтровать отчёт по периоду и счёту; смотреть категории, динамику по дням/месяцам и долю расходов в доходах; нажимать на диаграммы для подробностей.
- Экспортировать P&L и операции в CSV, делать JSON-копии, переносить их на другой iPhone.

## Примеры сообщений

- `зарплата 90000, кофе 250, такси 480`
- `подработка 5к; продукты 1450,50`
- `250 кофе 480 такси`
- `вчера булочка 100 шампунь 400`
- `перевёл с карты в накопления 5000`
- `вернули за кофе 250`
- `доход от аренды 25000`

Распознавание работает локально по правилам и словарям. Произвольную человеческую формулировку невозможно гарантированно разобрать без ошибок: неизвестные категории отмечаются, неоднозначные суммы отклоняются. Поэтому приложение всегда показывает предварительный результат. Предел — 20 операций за сообщение; валюта — рубли. Кредиты и долги автоматически не классифицируются как доход. Названия дополнительных счетов распознаются при точном совпадении с их названиями.

## Как считаются финансы

- Остаток счёта = начальная сумма + доходы + возвраты + входящие переводы − расходы − исходящие переводы.
- Переводы между своими счетами не входят в доходы, расходы и P&L.
- P&L = доходы − расходы + возвраты за выбранный период.
- Накопления — текущие остатки счетов, помеченных как накопительные.
- Доля потребления = (расходы − возвраты) / доходы. При отсутствии доходов процент не показывается.
- Свободный остаток в процентах = результат / доходы. Это не фактически отложенная сумма.
- Остатки считаются на текущий момент, без будущих операций. Начальные остатки относятся к началу учёта, а не к дате их редактирования.

## Быстрый старт

Нужны Mac, Xcode с поддержкой iOS 17 или новее и установленный iOS SDK. Исходники проверялись в Xcode 27. Приложение предназначено для iPhone, минимум iOS 17.

```sh
git clone https://github.com/1xMaFx1/MoneyBotik.git
cd MoneyBotik
python3 scripts/setup-dependencies.py
open MoneyBotik.xcodeproj
```

Скрипт один раз скачивает whisper.cpp 1.8.3 и мультиязычную модель Whisper base (~148 МБ), проверяя SHA-256. Интернет нужен для подготовки сборки; установленное приложение обрабатывает текст и голос локально. Сервер, Telegram и API-ключи не нужны.

Для симулятора выберите iPhone и нажмите Run. Для физического телефона выберите свою Team в Signing & Capabilities, задайте уникальный Bundle Identifier, включите режим разработчика и подтвердите доверие разработчику на iPhone. Бесплатная Personal Team требует периодического обновления подписи; публикация исходников на GitHub не заменяет подпись Apple.

Бюджеты на разных телефонах независимы. Доступен ручной перенос JSON-копии; автоматической синхронизации нет.

## Проверки

```sh
zsh scripts/check-core.sh
zsh scripts/check-voice.sh
zsh scripts/build-unsigned.sh
```

Основные проверки логики не требуют голосовых зависимостей. Для голосовой проверки нужен системный русский голос Milena. Подробнее: [TESTING.md](TESTING.md).

## Ограничения учебной версии

Это учебный прототип, а не банковский сервис. Проверяйте распознанные операции перед сохранением. Полный набор функций на всех физических iPhone не проверен; будущие версии iOS требуют повторного тестирования. Голосовые записи удаляются после обработки; импортированные исходные аудиофайлы не удаляются.

## Зависимости

- [whisper.cpp](https://github.com/ggml-org/whisper.cpp), версия 1.8.3, MIT.
- [Whisper](https://github.com/openai/whisper), модель base, MIT.

Тексты сторонних лицензий находятся в `Vendor/` и ресурсах приложения. Большие зависимости, подписи Apple и пользовательские данные в репозиторий не входят.

## Совместимость резервных копий

При переносе старой версии расходы сохраняются как расходы со счёта «Карта». Версия архива 2 добавляет счета и виды операций; версия 1 читается автоматически. Импорт в пустое приложение восстанавливает счета и начальные суммы. При объединении несовместимых настроек одного счёта импорт останавливается, чтобы не исказить баланс. Повторные записи по идентификаторам пропускаются; импорт не является синхронизацией изменений.
